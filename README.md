# 🧪 Automação de Testes com Selenium e MSTest

Projeto acadêmico desenvolvido em **C# com .NET 10**, utilizando **Selenium WebDriver** e **MSTest** para automatizar o preenchimento e envio de um formulário web.

## 📖 Sobre o projeto

Esta atividade tem como objetivo aplicar conceitos de **Garantia da Qualidade de Software**, demonstrando como automatizar interações com páginas web e validar resultados por meio de testes automatizados.

A automação utiliza o navegador Google Chrome para acessar um formulário de demonstração disponibilizado pelo Selenium.

## 🚀 Funcionalidades

- Abertura automática do navegador Google Chrome.
- Acesso ao formulário de testes do Selenium.
- Localização de elementos HTML utilizando seletores.
- Preenchimento automático de campos.
- Envio do formulário por meio do botão Submit.
- Leitura da mensagem de confirmação.
- Validação automatizada do resultado utilizando MSTest.
- Encerramento do navegador após a execução.
